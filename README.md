# Ehi Oko’s portfolio

Source for the portfolio at ehioko.com.

## Local preview

Use Node.js 20 or newer. No dependencies need installing.

- Run npm run dev and open http://127.0.0.1:4173/.
- Run npm run build to create dist/.
- Edit index.html, styles.css, and app.js; media is in assets/.

## Publishing

The GitHub repository is https://github.com/ehiokospace/portfolio.
Commits to main run .github/workflows/pages.yml and publish dist/ to GitHub Pages.
The custom domain is ehioko.com, registered at Namecheap.

## Preliminary version

Gallery, resume, and project case studies are placeholders. Email copies the contact address; social links are connected. Weather uses approximate viewer city location. The hero video is muted. Licensed custom font files are not bundled, so browser fallback fonts apply.
